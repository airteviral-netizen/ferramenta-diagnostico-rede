# Ferramenta de Diagnóstico de Rede

## Integrantes da Equipe
LUCAS e DEODENIZ

## Descrição da Aplicação
Aplicação desktop desenvolvida em Python com CustomTkinter para realizar diagnósticos básicos de rede, coleta de IP local e testes de conectividade via comando Ping de forma assíncrona.

## Principais Funcionalidades
- Exibição de informações do computador e rede (IP local, nome da máquina, interface).
- Execução de testes de conectividade (Ping) com tratamento de erros.
- Interface gráfica amigável e limpa.

## Tecnologias e Bibliotecas Utilizadas
- Python 3.x
- CustomTkinter (Interface Gráfica)
- psutil (Informações de Hardware e Rede)
- subprocess e threading (Execução de comandos do sistema de forma não-bloqueante)
